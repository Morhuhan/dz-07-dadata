# Проверка контрагента

Учебный проект к занятию 7. Спрашивает у сервиса Dadata данные о российской
фирме — ИНН, адрес, руководителя, действует она или ликвидирована — и
показывает их на странице.

## Запуск

```cmd
copy .env.example .env
notepad .env
node server.js
```

В блокноте вставить свой ключ Dadata после `DADATA_TOKEN=`, сохранить, закрыть.
Потом открыть http://localhost:3000

Остановить — `Ctrl+C` в том же окне.

## Где что лежит

| Файл | Что внутри |
|---|---|
| `.env` | ключ. Только на твоём компьютере, в репозиторий не попадает |
| `.env.example` | образец без ключа |
| `server.js` | принимает запрос от страницы и пересылает его в Dadata вместе с ключом |
| `index.html` | страница: поле, фильтры, карточки, сырой JSON |

Ключ живёт в `.env` и дальше `server.js` никуда не уходит.
Страница его не видит — она обращается только к `localhost`.
